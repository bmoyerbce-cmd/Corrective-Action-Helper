# Supervisor Counseling Forms

Static GitHub Pages version of the Supervisor Counseling / Disciplinary Form Builder.

## Files

- `index.html` - editable form builder
- `read.html` - read-only view for saved/shared drafts
- `assets/css/styles.css` - page styling
- `assets/js/app.js` - app logic
- `assets/js/read-mode.js` - read-only page behavior
- `assets/js/vendor/` - bundled browser export libraries used by the original page

## GitHub Pages

1. Upload these files to a GitHub repository.
2. In the repository settings, enable GitHub Pages from the main branch.
3. Open `index.html` to create or edit a form. Use **Save Draft** or **Read Page** to view the read-only version.

No build step is required.
